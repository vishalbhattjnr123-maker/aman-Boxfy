# aman-Boxfy

Boxfy AI Studio — Official Streaming & AI Cinema Platform.

## Features
- **Cinematic Streaming Experience**: Netflix & Apple TV+ grade dark-mode UI with ambient back-glow.
- **Universal Video Engine**: Plays YouTube (watch, shorts, live, embeds), Google Drive, Vimeo, and direct MP4/WebM cloud streams.
- **Dynamic Categories**: 3D Animation, AI Sci-Fi, Kuku Boy Superhero, Mahabharat Epics, AR/VR Gaming, and Brand Commercials.
- **Executive Leadership**: Featuring Dr. Ajay Sharma (CEO) and Aman Attal (Founder & Creative Director).
- **Interactive Player**: 4K quality badges, full controls, audio preview toggle, responsive carousel rows, and instant watch modal.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Built With
- **Next.js 16** (App Router, Turbopack)
- **Tailwind CSS**
- **Framer Motion**
- **Lucide Icons**
